# Student-Dost

**[▶ Live demo](https://student-dost.vercel.app)**

Student-Dost is a **frontend-only personal management dashboard** built using **HTML, CSS, and JavaScript**.  
It helps students manage **daily tasks, personal finances, and habits** in a single, simple interface.

The project is designed to be **UI/UX heavy** and **JavaScript driven**, with no backend or database dependency.

---

## 🚀 Features

### 🗂 Personal Productivity
- Add and view daily tasks
- Dynamic task list rendering using DOM manipulation
- Simple and distraction-free task management

### 💰 Finance Management
- Track income and expenses
- Categorize spending
- Real-time balance calculation
- Warning when expenses exceed income

### 🌱 Habit & Lifestyle Tracking
- Daily habit completion
- Automatic streak counter
- Instant visual feedback

---

## 🛠 Tech Stack

- **HTML** – Structure and layout
- **CSS** – Styling and UI/UX (no blue or purple colors)
- **JavaScript** – Logic, state handling, and DOM manipulation

> ❌ No backend  
> ❌ No database  
> ❌ No frameworks

## ▶️ How to Run

### Option 1: Direct Browser Run
1. Download or clone the project
2. Double-click `index.html`
3. The application runs in your browser

### Option 2: VS Code Live Server (Recommended)
1. Open the project in VS Code
2. Install the **Live Server** extension
3. Right-click `index.html`
4. Click **Open with Live Server**
